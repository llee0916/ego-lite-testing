# 官网和展示站点测试

以用户指定的设备、范围和测试强度为准。未指定时按项目规则选择桌面、手机和平板的视口模拟，记录实际宽高，不声称真机或跨浏览器覆盖；默认检查首页、主导航一级页面和页脚主要链接，不自动进行全站遍历。

- 检查首屏标题、Logo、主图或视频、主要内容是否加载；必要时查看截图确认破图、遮挡、溢出和文字可读性。记录大致加载感知，不设未经约定的硬性阈值。
- 通过实际点击检查在范围内的导航、按钮、卡片和页脚链接是否到达预期页面，记录链接文字、目标和实际落点；检查适用的返回、菜单展开、搜索、轮播或其他关键交互。外部站点不扩大为全站测试。
- 检查可见内容、联系方式、隐私政策、条款、Cookie 提示、页面标题和图标；无法独立验证真实性时注明限制，不臆断。
- 表单查看字段和提示；生产环境只读，未经明确授权不提交、订阅、发送询盘、注册或触发真实通知。未验证提交结果要在报告中说明。
- 在约定视口检查内容溢出、重叠、固定区域和可操作性；视觉问题保留并实际查看截图。区分桌面、模拟视口及未覆盖设备。
