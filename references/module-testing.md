# 模块测试

根据当前模块页面和需求选择适用场景；未提供需求时将没有规则依据的行为标记为待业务确认。用户明确限制测试强度或范围时遵从该要求。默认不测试中文输入。

## 列表与查询

- 检查初始加载、加载中、空结果、结果总数和字段展示。精确、模糊、大小写、空白、特殊字符、无结果等查询按实际搜索范围和数据条件覆盖。
- 逐项检查实际存在的筛选字段、状态和开关，包括默认值、可用选项、包含与排除、清空/重置，以及与关键词、其他筛选和分页的代表性组合。无需穷举全部组合；记录未覆盖的选项和选取依据。用已知匹配及不匹配数据验证。
- 对每个可排序列，在有可区分数据时验证升序、降序的实际顺序；按风险检查相同值、空值、跨页及筛选后的排序一致性。仅点击按钮或观察图标不能证明排序通过。
- 检查首尾页、前后翻页、页大小、总数及筛选后分页状态；分页内没有目标不代表全局不存在。
- 等待新查询实际完成后再读取结果，排除旧列表、加载遮罩及残留筛选；无结果应有明确空态或加载结束证据。
- 对行操作和选择后的批量工具栏分别观察命令、选中范围和实际结果；在授权内只使用本轮测试记录验证取消、确认和刷新。不存在某操作时记录不适用或受权限阻塞，继续其他场景。

## 表单、详情与状态

- 覆盖页面实际提供的新增、查看、编辑、删除、启停或其他状态流转，以及列表与详情的一致性。记录复选框默认值及操作后真实状态；不强行解除 disabled 或 readonly。
- 按需求及页面行为检查必填、非必填、默认值、空白、长度、英文/数字/混合及特殊字符、类型、枚举、格式、字段联动、重复值、大小写和前后空格。数值及长度边界以需求为准；规则缺失时不自行发明验收值。
- 检查提交、取消、错误位置、错误后输入保留及修正重试；重复提交和异常输入仅对授权测试数据进行，并确认不会触发真实通知或审批。
- 保存后重新查询或打开详情、编辑页，核对唯一标识和关键字段。输入框值、点击回执、浏览器 validity 或单次快照不能替代持久化结果。
- 确认提示和取消路径应按实际场景验证。原生弹窗使用 ego-browser 的 accept/dismiss 接口，不覆盖浏览器原生函数或自动接受所有确认。

## 文件上传

- 根据需求和页面提示确认上传入口、允许的文件类型、数量和大小限制，以及上传是否会立即保存或触发其他操作。规则不明确时记录实际行为并标记待业务确认，不自行设定验收标准。
- 在授权范围内尽可能覆盖不同文件类型，优先验证业务允许的各类文件，并选取有代表性的不支持类型检查提示和处理结果。记录实际测试的类型、结果及未覆盖范围；不要仅凭文件选择器的过滤规则认定校验通过。
- 分别检查单文件和多文件上传：验证文件选择、展示和上传结果，以及页面提供的追加、替换、移除、取消等操作。若只支持其中一种模式，记录依据及另一种模式不适用或受阻的原因；不要通过修改页面或接口绕过限制。
- 文件大小测试不强求。条件允许且存在明确限制时，按风险选择限制内及超限文件验证；报告中明确是否测试大小、使用的大小和结果，未测试时说明原因与覆盖限制。
- 检查上传过程和完成、失败状态及错误提示；适用时检查重复文件、特殊字符文件名、空文件和失败后重试。仅在明确规则或可观察到的业务预期支持时判断缺陷，不制造可能影响其他用户的异常或负载。
- 上传后通过重新打开记录或页面确认文件是否持久化，并按页面能力核对文件名、数量及预览或下载结果；选择文件或出现成功提示不能单独证明最终保存成功。仅使用本轮测试文件和记录，按实际能力清理并记录残留。
- 遵守执行参考文件中的环境和授权规则。上传不可执行或受阻时记录入口、已尝试步骤、具体原因、未覆盖范围及证据，继续其他独立测试，不因此终止任务。

## 导入与导出

- 观察单项、选中项、筛选结果和全部等实际入口及模板、格式、必填列、覆盖规则和副作用；分别记录入口发现和功能验证，不将可见入口等同于通过。
- 在确认的非生产测试环境及授权范围内，以唯一标记的少量测试数据检查正常导入、格式或必填错误、重复值和反馈，并按页面能力检查预览、取消、部分成功和导入后重新查询。避免覆盖或修改既有记录；可能触发真实通知、审批或其他实质副作用且授权不明时先确认，继续其他独立场景。
- 对可用导出模式检查下载完成、文件名、格式，以及内容与所选记录或筛选结果的一致性；安全可读时检查表头、关键字段和数量。控制敏感数据的导出范围、保存位置和报告内容。
- 生产环境写入、导入、上传和导出遵守执行参考文件中的生产规则；缺少模板、权限或可安全处置的数据时记录具体阻塞和未执行范围，不通过接口绕过 UI 或授权。
